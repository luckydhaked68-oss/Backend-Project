# 🎬 Video-Sharing Platform – Backend

## 📌 Project Summary

This project is a comprehensive backend application for a video-sharing platform similar to YouTube, built using **Node.js, Express.js, MongoDB, Mongoose, JWT, Bcrypt, and JavaScript**.

The project focuses on developing a complete backend system that supports essential video-sharing platform functionalities, including:

### 🚀 Key Features

- **User Authentication:** Secure user registration and login using JWT and Bcrypt.
- **Video Management:** Upload, retrieve, update, and delete video content.
- **Like & Dislike:** Allows users to interact with videos.
- **Comment Management:** Create, retrieve, update, and delete comments with pagination and ownership validation.
- **Reply System:** Supports replies to comments.
- **Channel Subscription:** Subscribe and unsubscribe functionality.
- **Dashboard Analytics:** Provides channel statistics, including total videos, views, subscribers, and likes.
- **Health Check API:** Monitors server availability and returns structured JSON responses.

### 🔐 Security & Backend Practices

The project follows standard backend development practices, including:

- JWT-based authentication and authorization.
- Password hashing using Bcrypt.
- Access Token and Refresh Token management.
- Ownership validation for protected operations.
- Structured API responses.
- MongoDB database integration using Mongoose.
